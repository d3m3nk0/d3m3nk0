# AGENTS.md — правила разработки d3m3nk0

Этот файл читает ИИ, который пишет код d3m3nk0 (OpenCode или другой агент).
Правила для самого d3m3nk0, когда он выполняет задания, лежат в его рабочей
папке, а не здесь.

## Проект

d3m3nk0 — десктопный агент для работы с кодом на Node.js 22+ и Electron.
Архитектура описана в `docs/ARCHITECTURE.md`, читай его перед большими правками.
Порядок работы (ветки, проверка, перенос в песочницу) описан в `docs/DEVELOPMENT.md`.

| Папка / файл | Что там |
|---|---|
| `src/core/agent.js` | агентный цикл, системный промпт, политика доступа |
| `src/core/tools.js` | встроенные инструменты и границы рабочей папки |
| `src/core/providers.js` | запросы к Anthropic и OpenAI-совместимым API |
| `src/core/mcp.js` | клиент MCP-серверов |
| `src/core/context.js` | обрезка контекста |
| `src/core/session.js` | журнал сессий (JSONL) |
| `src/main/`, `src/renderer/` | окно Electron |
| `cli.js` | режим терминала |
| `test/` | тесты, модель подменяется `test/helpers/fake-llm.js` |

## Команды

- `npm test` — проверка инструментов и границ папки (`test/smoke.js`).
- `npm run test:regression` — регрессионные тесты.
- `npm run test:mcp` — проверка MCP-клиента.
- `npm start` — окно, `node cli.js` — терминал.

## Как работать

1. Делай всё сам. Спрашивай пользователя только то, что не можешь решить сам.
2. Перед установкой или запуском чего-то нового напиши одну строку: что это и зачем.
3. Одна функция за раз: сделал → проверил тестами → коммит → следующая.
4. **«Готово» — это заявление, а не факт.** Не пиши, что работает, пока не
   прошли `npm test` и `npm run test:regression`. Не пиши, что файл создан,
   пока не увидел его в листинге папки.
5. Нашёл и исправил ошибку — добавь тест, который её ловит.
6. Новые зависимости npm — только после вопроса пользователю.
7. Тесты работают только во временных папках (`os.tmpdir()`) и с
   `D3M3NK0_HOME` во временной папке. Не трогай настоящий
   `~/.d3m3nk0/config.json` и не создавай файлов в корне проекта.
8. Коммиты маленькие, сообщение говорит, что изменилось и зачем.
   Ничего не пушь без просьбы пользователя.

## Запреты

- **Ключи API никогда не попадают в репозиторий**, в логи и в тесты. Они живут
  только в `~/.d3m3nk0/config.json` или в `.d3m3nk0/` (закрыто в `.gitignore`).
- Не открывай и не изменяй папки `harness_*` и установщики `*.exe`: это чужие
  программы, а не часть проекта.
- **Не разбирай Claude, Claude Code и другие закрытые приложения** (REA, Ghidra,
  распаковка бандлов): это запрещают их условия использования. Идеи бери только
  из открытых источников: публичная документация Claude Code, исходники
  OpenCode, документация MCP.
- Не копируй чужой код. Пиши свой.
- Не включай `yolo` по умолчанию и не ослабляй границы рабочей папки без просьбы.
