# Как развивать d3m3nk0 — шпаргалка

## 1. Кто есть кто

| Папка | Роль | Что там делаю |
|---|---|---|
| `C:\Users\ele8e\d3m3nk0` | **мастерская** | пишу и чиню код, ветки, тесты, коммиты |
| `C:\Users\ele8e\d3m3nk0_sandbox` | **рабочая версия** | только пользуюсь агентом, код руками **не трогаю** |
| `C:\Users\ele8e\d3m3nk0_work` | задания для агента из мастерской | сюда агент пишет файлы |
| `C:\Users\ele8e\d3m3nk0_sandbox\work` | задания для рабочей версии | RDM, письма, всё «настоящее» |

Код живёт **только** в `d3m3nk0`. Песочница получает его через `git pull`.

## 2. Цикл одного улучшения

Все команды выполняются в PowerShell, в папке `C:\Users\ele8e\d3m3nk0`.

**Шаг 1. Начать: новая ветка на одну идею**
```powershell
cd C:\Users\ele8e\d3m3nk0
git switch main
git switch -c idea-retry
```
Имя ветки: `idea-` + коротко, о чём идея (`idea-retry`, `idea-vision`, `fix-picker`).

**Шаг 2. Попросить OpenCode сделать**
Открыть OpenCode в папке `d3m3nk0` и написать:
> Прочитай AGENTS.md. Сделай одну вещь: <что именно>. Добавь тест.
> Запусти npm test и npm run test:regression. Не говори «готово», пока всё не зелёное.
> Сделай коммит.

**Шаг 3. Проверить самому** (не верить на слово)
```powershell
npm test
npm run test:regression
npm start
```
Тесты должны быть без `FAIL`. Затем открыть окно и попробовать новую вещь руками.

**Шаг 4а. Получилось: перенести в main**
```powershell
git switch main
git merge idea-retry
git branch -d idea-retry
```

**Шаг 4б. Не получилось: выбросить**
```powershell
git switch main
git branch -D idea-retry
```
Main не тронут, как будто ничего и не было.

**Шаг 5. Обновить рабочую версию**
```powershell
cd C:\Users\ele8e\d3m3nk0_sandbox
git pull
```

**Шаг 6. (по желанию) Отправить на GitHub**
```powershell
cd C:\Users\ele8e\d3m3nk0
git push origin main
```

## 4. Если что-то сломал

| Ситуация | Команда |
|---|---|
| Испортил файл, ещё не коммитил | `git restore путь\к\файлу` |
| Испортил всё в ветке, ещё не коммитил | `git restore .` |
| Посмотреть историю | `git log --oneline -10` |
| Отменить плохой коммит, который уже в main | `git revert <номер коммита>` |
| Не понимаю, где я | `git status` и `git branch` |

Песочница от всего этого не страдает, пока не сделан `git pull`.

## 5. Правила, которые не нарушаю

1. **Ключи API** только в настройках агента (`~/.d3m3nk0/` или `.d3m3nk0/`), никогда в коде и не в чатах.
2. **Одна ветка — одна идея.** Не смешивать.
3. **Реверс: только open-source** (OpenCode и другие). Идеи для d3m3nk0
   черпаем из открытых исходников и документации. Закрытые продукты
   не разбираем — их лицензии это запрещают.
4. **Режим `yolo` не включать** без нужды. По умолчанию `allow-edits` или `ask`.
5. Правила для ИИ-разработчика лежат в `AGENTS.md` в корне репозитория. Правила для самого агента лежат в `AGENTS.md` его рабочей папки. Если агент делает что-то не так, дописать правило туда.
6. Агент может предлагать новые правила для файлов инструкций, но добавляет
   их только с явного согласия пользователя. Каждая правка файла инструкций
   упоминается в отчёте агента отдельно.
